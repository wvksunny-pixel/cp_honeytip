# 기파팀 Claude Code 바이브코딩 실전 가이드

월드비전 기업파트너십팀(기파팀) 팀원들이 **Claude Code + GPT**로 기업 후원 결과보고를 웹페이지로 만들어 보는 교육용 홈페이지입니다. 코딩을 몰라도 따라 할 수 있도록 7단계로 구성했습니다.

> 이 홈페이지에 나오는 **‘배민 2026 도시락 사업’과 그 안의 모든 사업 내용·수치·학교 정보는 교육용 가상 예시**입니다. 실제 사업 데이터가 아닙니다. 화면에서도 `교육용 가상 예시` 표시로 구분했습니다.

## 여는 방법

설치할 것이 없습니다. 이 폴더의 **`index.html`을 더블클릭**하면 브라우저(Chrome, Edge 권장)에서 열립니다.

- 글꼴(Pretendard)만 인터넷에서 불러옵니다. 인터넷이 없어도 기본 글꼴로 정상 동작합니다.
- 팀원에게 공유할 때는 폴더(`gipa-vibecoding-guide`)째 OneDrive로 공유하면 됩니다.

복사 버튼이 막히는 환경이라면 간단한 로컬 서버로 열어도 됩니다(선택).

```bash
python -m http.server 8790
```

그다음 브라우저에서 http://localhost:8790 을 엽니다.

## 구성

| 섹션 | 내용 | 실제로 동작하는 기능 |
| --- | --- | --- |
| 인트로 | 메인 카피, 핵심 메시지, 요리 비유, **사전 숙제**(Claude Code 설치·GitHub 가입) | 시작 버튼, 숙제 체크(저장) |
| 전체 흐름 | 0~7단계 흐름, GPT vs Claude Code 역할 | 단계 카드 클릭 → 해당 설명으로 이동 |
| PART 1 그림 먼저 | 선영식 ‘그림 먼저, 퍼즐 맞추기’ 5단계 | — |
| PART 1 예시 | 배민 2026 도시락 지원사업(가상) 퍼즐 5조각, 지도 설계 예시 | 가상 학교 점 클릭 → 정보 카드 |
| PART 1 두 방식 | 선영식(그림 먼저) vs 빠른 초안형 동등 비교, 참고 가이드 링크 | — |
| PART 1 내 스타일 | A 그림부터 / B 일단 만들기 / C 둘 다 | 선택에 따라 안내 변경, A는 워크시트 → 설계안 → GPT 프롬프트(복사), 선택값은 STEP 4 프롬프트에도 반영 |
| 제작기 (맨 끝) | 이 홈페이지를 만든 실제 기록: 내가 GPT에 쓴 날것의 말 → GPT가 정리한 프롬프트 → Claude Code 작업 → 마이크로 수정(고도화 프롬프트 포함) | 프롬프트 전체 펼치기·복사 |
| STEP 1 설치 | 공식 문서 기준 설치·확인·실행 방법 | Windows/macOS 탭, 명령어 복사 |
| STEP 2 재료 | OneDrive·폴더 구조, 아동보호 주의 | 재료 체크리스트(브라우저에 저장) |
| STEP 3 추구미 | 스타일 A~D, 분위기, 구성, 데이터, 활용 선택 | 선택 즉시 STEP 4 프롬프트 갱신(선택값 저장) |
| STEP 4 레시피 | 날것/다듬은 GPT 요청 예시, 단순 요청 → 기획형 프롬프트 비교, 역할 구분 | 프롬프트 자동 생성 + 복사 + 복사 후 안내 |
| STEP 5 실행 | Claude Code 실행 프롬프트, 안전 점검 | 프롬프트 복사 |
| STEP 6 간 맞추기 | 마이크로 수정 카드 7종, 의도 기반 수정 공식(원래 의도 → 현재 문제 → 수정 요청 → 결과 확인), 원칙 | 카드별 복사, 수정 프롬프트 만들기(입력 → 자동 완성 → 복사) |
| STEP 7 검수·공유 | 최종 체크리스트, 공유 방법 비교, 외부 호스팅 주의 | 체크 진행률(저장), 초기화 |

각 섹션 끝에는 ‘다음 →’ 링크가, 상단에는 읽기 진행 막대가 있어 긴 화면도 순서대로 이어 볼 수 있습니다.

체크 상태·선택값·워크시트 답변은 **이 브라우저에만**(localStorage) 저장됩니다. 서버나 다른 사람에게 전송되지 않습니다. 외부 API나 계정 연결 기능은 없습니다.

## 파일 구조

```
gipa-vibecoding-guide/
├─ index.html        페이지 내용(문구는 대부분 여기서 수정)
├─ css/styles.css    디자인(맨 위 :root에서 색상 변경)
├─ js/prompt.js      GPT 프롬프트 생성 문구(스타일별 설명·챕터 등)
├─ js/making-of.js   제작기에 실린 실제 입력값(내가 GPT에 쓴 말, GPT가 정리한 프롬프트, 고도화 프롬프트)
├─ js/design-plan.js 워크시트 → 설계안 → GPT 프롬프트, 의도 기반 수정 프롬프트 문구
├─ js/app.js         버튼·선택·복사·체크리스트 동작
└─ README.md
```

## 수정하는 방법

이 폴더에서 Claude Code를 열고 평소처럼 부탁하면 됩니다. 예:

- “STEP 6에 ‘표 수정’ 카드를 하나 추가해줘. 다른 카드와 똑같이 복사 버튼도 넣어줘.”
- “스타일 B(사진 중심)를 골랐을 때 프롬프트에 ‘사진 파일명과 캡션을 표로 먼저 정리’하는 문장을 추가해줘.” → `js/prompt.js`
- “포인트 오렌지를 조금 더 진하게 바꿔줘.” → `css/styles.css`의 `--brand`(월드비전 오렌지), `--accent`(글자용 진한 오렌지)

직접 고친다면 메모장이나 VS Code로 파일을 열어 글자만 바꾸고 저장한 뒤 브라우저를 새로고침하세요.

## 참고 · 업데이트 주의

- Claude Code 설치 명령어는 **2026년 10월 공식 문서**(https://code.claude.com/docs/en/setup) 기준입니다. 교육 전에 공식 문서와 한 번 대조해 주세요.
- Claude Code 사용에는 Pro·Max·Team·Enterprise 또는 Console 계정이 필요합니다(무료 플랜 미포함).
- STEP 5의 “Claude Code가 거치는 과정”은 교육용으로 정리한 흐름이며, 실제 응답 문장을 재현한 것이 아닙니다.
